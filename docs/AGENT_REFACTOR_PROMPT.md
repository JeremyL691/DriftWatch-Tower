## 使用说明

本提示词把产品实施与发布交给接手 Agent，不要求它依靠不存在的权限或绕过平台限制。文档只能明确自主执行协议，无法保证任意平台的额度、唤醒或外部服务永远可用。发生限制时，保留可恢复状态并真实报告；目标仍未完成。

产品完成条件与实现细节以[执行指南](PROJECT_EXECUTION_GUIDE.md)为准，进度以[执行状态](EXECUTION_STATE.md)为准。
